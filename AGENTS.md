# Ashen Pity Repository Rules

- Keep scenes small and focused.
- Keep scripts under reasonable size.
- Separate combat logic from rendering logic.
- Use signals intentionally.
- Avoid giant manager classes.
- Avoid hardcoding values scattered across scripts.
- Keep balance values centralized.
- Test pure gameplay logic with headless scripts.
- Run the project before every commit.
- Never add copyrighted assets.
- Never add dead or duplicate code without explanation.
